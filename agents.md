# Agent Rules For `NFLverse`

Keep it simple and keep it reliable.

## Main Rules

- Do not make up data, sources, schemas, or metrics.
- If something is unclear, call it out instead of guessing.
- Keep NFL and CFB logic separate unless the repo clearly wants them combined.
- Prefer scripts and repeatable workflows over manual edits.
- Keep raw, staging, and cleaned data separate.
- Update the docs when the workflow changes.
- Run checks when you change code or processing logic.
- Avoid destructive changes unless you were explicitly asked to make them.

## General Approach

- Keep code reusable instead of hiding logic in notebooks.
- Keep field names and file names clear.
- Keep changes small when possible.
- Keep source notes close to the code or data they belong to.
